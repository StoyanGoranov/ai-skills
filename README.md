# ai-skills

This is a repository for agentic skills which aim to aid humans to interactively learn, think critically and self-actualize instead of fully outsourcing their cognition into autonomous processes.

## Skills

### learn-by-doing

Helps students learn instead of just receiving answers. When a student asks for an explanation or help with a task, Claude:

1. Asks how deep to go (quick overview / solid understanding / deep dive).
2. Starts with a practical analogy or the simplest explanation.
3. Explains the topic in parts, core concepts first, then consequences and details.
4. Has the student assemble the concepts and solve the problem themselves, guiding with hints and questions rather than giving the answer.

**Usage:** copy `skills/learn-by-doing` into your skills folder (e.g. `~/.claude/skills/`), then ask something like "Help me understand recursion" or "I'm stuck on this exercise, teach me how to solve it".
